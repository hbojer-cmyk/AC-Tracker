⚡ Cloudflare KV Telemetry Setup Required

The backend API function (/api/telemetry) is deployed and ready, but requires a free Cloudflare KV namespace binding to store global player heartbeats. Follow these 2 quick steps in your Cloudflare dashboard:

Step 1 — Create KV Namespace
Go to Cloudflare Dashboard → Storage & Databases → KV.
Click Create a namespace and name it AC_TELEMETRY.
Step 2 — Bind Variable
Go to Workers & Pages → ac-tracker → Settings → Functions.
Scroll to KV namespace bindings → Click Add binding:
• Variable name: TELEMETRY_KV
• KV namespace: AC_TELEMETRY
Step 3 — Re-check Connection
Once saved, click the test button below to verify global player tracking is live!
